Instalar e entrar no Kali dentro do Termux

instalar kalinethunterconfigurar termuxnh -rkali
pkg update && pkg upgrade -y pkg install wget -y wget -O install-nethunter-termux https://offs.ec/2MceZbN chmod +x install-nethunter-termux ./install-nethunter-termux -l # depois de instalado, para entrar: nh -r (ou: kali / nethunter)
📋 Passo a passo
  1. Abra o Termux e rode: pkg update && pkg upgrade -y
  2. Instale o wget: pkg install wget -y
  3. Baixe o instalador: wget -O install-nethunter-termux https://offs.ec/2MceZbN

  5. Execute: ./install-nethunter-termux -l
  6. Para entrar no Kali depois: use nh -r (root) ou kali/nethunter.
  7. Dentro do Kali use apt para instalar ferramentas.
💡 A forma de entrar varia: nh, nh -r, kali ou nethunter. Verifique a sua.
