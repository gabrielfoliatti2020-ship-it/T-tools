🖥️ Baixar cada desktop gráfico (comandos completos)
Aqui estão todos os desktops gráficos que você pode instalar no celular. Cada um com os comandos completos, do zero. Quanto mais leve, melhor roda no celular. Comece pelo cartão 1. Preparação e depois escolha o seu.
1️⃣ Preparação — base igual para TODOS

Faça isso uma vez. Depois você só escolhe o desktop nos cartões seguintes.

Passo 1 — no Termux (fora da distro) pkg update && pkg upgrade -y pkg install proot-distro -y pkg install x11-repo -y Passo 2 — instale uma distro base (Ubuntu é a mais fácil) proot-distro install ubuntu Passo 3 — entre na distro proot-distro login ubuntu Passo 4 — já dentro do Ubuntu, atualize e instale o básico apt update && apt upgrade -y apt install sudo nano wget curl -y Passo 5 — no celular, instale um app de VNC (Play Store)

Baixe VNC Viewer (RealVNC) ou bVNC. É por ele que você vai ver a tela do Linux.

🖱️ 2. XFCE4 — leve e recomendado

O melhor equilíbrio: bonito, leve e rápido no celular. Comece por ele.

Instalar o desktop apt install xfce4 xfce4-goodies xfce4-terminal -y Instalar o servidor VNC apt install tigervnc-standalone-server tigervnc-common -y Criar a senha do VNC (peça 6–8 caracteres) vncpasswd Criar o arquivo de inicialização nano ~/.vnc/xstartup

Cole dentro do arquivo:

#!/bin/sh unset SESSION_MANAGER unset DBUS_SESSION_BUS_ADDRESS exec startxfce4 Dar permissão e iniciar chmod +x ~/.vnc/xstartup vncserver -geometry 1280x720 -depth 24 :1 Parar o VNC quando quiser vncserver -kill :1

Conectar: abra o VNC Viewer → endereço localhost:5901 → senha que você criou. Pronto! 🎉

🪶 3. LXQt — mais leve que o XFCE4

Ideal para celular fraco ou com pouca memória.

apt install lxqt lxqt-config lxqt-policykit qterminal -y apt install tigervnc-standalone-server -y vncpasswd nano ~/.vnc/xstartup

Cole dentro:

#!/bin/sh unset SESSION_MANAGER exec startlxqt chmod +x ~/.vnc/xstartup vncserver -geometry 1280x720 -depth 24 :1

Conecte no VNC Viewer em localhost:5901.

🌿 4. MATE — médio, bem completo

Parecido com o visual clássico do Windows/Linux antigo.

apt install mate-desktop-environment mate-desktop-environment-extras -y apt install tigervnc-standalone-server -y vncpasswd nano ~/.vnc/xstartup

Cole dentro:

#!/bin/sh unset SESSION_MANAGER exec mate-session chmod +x ~/.vnc/xstartup vncserver -geometry 1280x720 -depth 24 :1
🍃 5. Cinnamon — médio-pesado, bonito

Visual moderno, parecido com Windows 10. Pede um celular melhor.

apt install cinnamon cinnamon-core nemo -y apt install tigervnc-standalone-server -y vncpasswd nano ~/.vnc/xstartup

Cole dentro:

#!/bin/sh unset SESSION_MANAGER exec cinnamon-session chmod +x ~/.vnc/xstartup vncserver -geometry 1280x720 -depth 24 :1
🔵 6. KDE Plasma — pesado, muito completo

O mais bonito e customizável, mas pesado. Use só se seu celular for potente.

apt install kde-plasma-desktop kde-standard -y apt install tigervnc-standalone-server -y vncpasswd nano ~/.vnc/xstartup

Cole dentro:

#!/bin/sh unset SESSION_MANAGER exec startplasma-x11 chmod +x ~/.vnc/xstartup vncserver -geometry 1280x720 -depth 24 :1
🟣 7. GNOME — o mais pesado

Só para celulares com bastante RAM (8GB+). Fica lento em aparelhos fracos.

apt install gnome gnome-tweaks gnome-terminal -y apt install tigervnc-standalone-server -y vncpasswd nano ~/.vnc/xstartup

Cole dentro:

#!/bin/sh unset SESSION_MANAGER export XDG_SESSION_TYPE=x11 exec gnome-session chmod +x ~/.vnc/xstartup vncserver -geometry 1280x720 -depth 24 :1
⬛ 8. Openbox — ultra leve (quase sem interface)

Roda em qualquer celular. Só uma barra e um menu — o mínimo possível.

apt install openbox obconf menu tint2 -y apt install tigervnc-standalone-server -y vncpasswd nano ~/.vnc/xstartup

Cole dentro:

#!/bin/sh exec openbox-session chmod +x ~/.vnc/xstartup vncserver -geometry 1280x720 -depth 24 :1
🪟 9. i3 — ultra leve (janelas em mosaico)

Sem mouse: as janelas se organizam sozinhas em grade. Muito rápido e moderno.

apt install i3 i3status dmenu xterm -y apt install tigervnc-standalone-server -y vncpasswd nano ~/.vnc/xstartup

Cole dentro:

#!/bin/sh exec i3 chmod +x ~/.vnc/xstartup vncserver -geometry 1280x720 -depth 24 :1
🔌 10. Termux:X11 — mais rápido que o VNC

Em vez de VNC, use o Termux:X11: a imagem fica muito mais fluida no celular.

No Termux (fora da distro) pkg install x11-repo -y pkg install termux-x11-nightly -y

Instale também o APK do Termux:X11 (no GitHub do termux-x11) e abra ele.

Entre na distro compartilhando o /tmp proot-distro login ubuntu --shared-tmp Ligue o servidor X11 export DISPLAY=:0 termux-x11 :0 & Agora inicie o desktop (exemplo XFCE4) apt install xfce4 xfce4-goodies -y startxfce4

Abra o app Termux:X11 para ver a tela. Para KDE/LXQt troque o último comando pelo do seu desktop.

⚖️ 11. Qual escolher? (peso e RAM)

• Openbox / i3 → 🟢 ultra leve (~100 MB) — celular fraco
• LXQt → 🟢 leve (~200 MB) — muito recomendado
• XFCE4 → 🟢 leve (~300 MB) — melhor escolha geral
• MATE → 🟡 médio (~450 MB)
• Cinnamon → 🟠 médio-pesado (~600 MB)
• KDE Plasma → 🔴 pesado (~800 MB)
• GNOME → 🔴 mais pesado (~1 GB+)

Regra: se seu celular tem menos de 6 GB de RAM, fique no XFCE4, LXQt, Openbox ou i3.

🆘 12. Problemas comuns e soluções

• VNC preto/vazio → o xstartup está errado. Confira se colou o exec startxfce4 (ou o do seu desktop) e deu chmod +x.
• Não conecta → use localhost:5901 (a porta do display :1 é 5901).
• Erro de DBus → normal no proot, ignore ou instale apt install dbus-x11 -y.
• Sem som → instale apt install pulseaudio -y.
• Travou → mate com vncserver -kill :1 e suba de novo.
• Teclado não abre → no app VNC, use o botão de teclado/ícone do canto.
• Muito lento → troque para Termux:X11 ou um desktop mais leve.

Arch Linux — guia para iniciantes
🏔️ Arch Linux é o sistema "avançado": ele começa vazio e você monta tudo do seu jeito. É o mais poderoso e o que mais ensina — mas exige paciência. Aqui vai o guia completo, do zero, com os comandos mais usados.
🧠 1. O que é o Arch Linux?

Arch é uma distribuição Linux. Ela é chamada de "avançada" porque não vem pronta: você instala o básico e adiciona o resto aos poucos. Isso assusta no começo, mas é a melhor forma de entender como o Linux funciona de verdade.

Ubuntu / Debian → já vêm com tudo instalado, são fáceis.
Arch → vem "cru", você escolhe cada peça. É o Lego do Linux.

Vantagem: está sempre atualizado e você aprende muito.
Desvantagem: precisa ler e digitar comandos com calma.

📥 2. Instalar o Arch no celular (Termux)
Passo 1 — atualize o Termux pkg update && pkg upgrade -y Passo 2 — instale o proot-distro pkg install proot-distro -y Passo 3 — instale o Arch proot-distro install archlinux Passo 4 — entre no Arch proot-distro login archlinux Passo 5 — sair quando quiser exit

Pronto! Você está dentro do Arch. O primeiro comando lá dentro é sempre atualizar o sistema (próximo cartão).

📦 3. pacman — o coração do Arch

No Arch, quem instala e remove programas é o pacman. Estes são os comandos que você mais vai usar na vida:

Atualizar tudo (faça isso sempre ao entrar) pacman -Syu Instalar um programa pacman -S nome-do-programa Remover um programa pacman -R nome-do-programa Remover o programa + dependências pacman -Rs nome-do-programa Buscar um programa pacman -Ss palavra-chave Ver informações de um pacote pacman -Si nome-do-programa Listar o que já está instalado pacman -Q Limpar o cache (libera espaço) pacman -Sc Instalar sem pedir confirmação pacman -S --noconfirm nome-do-programa

Dica: -S = instalar · -R = remover · -Q = consultar · -Syu = atualizar tudo.

🌟 4. AUR + yay (programas que não existem no pacman)

O AUR é uma "comunidade" com milhares de programas extras. Quem acessa o AUR é o yay. Primeiro instale o yay:

Prepare as ferramentas de compilação pacman -S --needed git base-devel Baixe e instale o yay git clone https://aur.archlinux.org/yay.git cd yay && makepkg -si Agora use o yay como se fosse pacman yay -S nome-do-programa yay -Ss palavra-chave yay -Syu

O yay faz tudo que o pacman faz e também busca no AUR. Muito prático!

🔧 5. systemctl — ligar e desligar serviços

Serviços são programas que ficam rodando em segundo plano (Wi-Fi, SSH, servidor web). Quem manda neles é o systemctl:

Ver se um serviço está ativo systemctl status nome-servico Iniciar / parar agora systemctl start nome-servico systemctl stop nome-servico Fazer iniciar junto com o sistema systemctl enable nome-servico systemctl disable nome-servico Listar todos os serviços rodando systemctl list-units --type=service Ver os últimos erros do sistema journalctl -xe
👤 6. Usuários, senha e sudo
Criar um usuário novo useradd -m joao Definir a senha dele passwd joao Dar poderes de administrador (grupo wheel) usermod -aG wheel joao Trocar para esse usuário su - joao Quem sou eu? / ver meu id whoami id Rodar algo como administrador sudo pacman -Syu

Atenção: o sudo dá poder total. Só use quando souber exatamente o que o comando faz.

📁 7. Arquivos e pastas (o básico que serve pra tudo)
Ver onde estou pwd Listar arquivos (com detalhes) ls -la Entrar numa pasta / voltar cd /etc cd .. Criar pasta mkdir minhapasta Copiar / mover / renomear cp arquivo.txt /tmp/ mv antigo.txt novo.txt Apagar (cuidado!) rm arquivo.txt rm -r minhapasta Ver o conteúdo de um arquivo cat arquivo.txt Editar um arquivo de texto nano arquivo.txt Dar permissão de execução chmod +x script.sh
🌐 8. Internet e Wi-Fi
Ver meu endereço de rede ip a Testar conexão ping google.com Ver meu IP público curl ifconfig.me Instalar o gerenciador de Wi-Fi pacman -S networkmanager systemctl enable --now NetworkManager Listar redes Wi-Fi nmcli device wifi list Conectar numa rede nmcli device wifi connect "MinhaRede" password "minhasenha"
🖥️ 9. Colocar um desktop gráfico (opcional)

O Arch puro é só terminal. Se quiser uma tela com janelas, instale o XFCE4 (leve):

pacman -S xorg-server xorg-xinit pacman -S xfce4 xfce4-goodies pacman -S lightdm lightdm-gtk-greeter systemctl enable lightdm Ou iniciar direto, sem gerenciador startxfce4

Para ver isso no celular, use o Termux:X11 ou VNC (veja a aba Simples → métodos).

🆘 10. Dicas de sobrevivência no Arch

• Leia antes de apertar Enter. O pacman mostra o que vai fazer — confira.
• man comando → abre o manual completo de qualquer comando.
• comando --help → resumo rápido das opções.
• Ctrl + C → cancela o que estiver rodando.
• clear → limpa a tela.
• history → mostra tudo que você digitou antes.
• Tab → completa o nome do arquivo/comando sozinho (use muito!).
• Se travar, exit sai e proot-distro login archlinux entra de novo.
• Nunca rode rm -rf / — isso apaga o sistema inteiro.

📚 11. Glossário rápido

• Pacote → um programa pronto para instalar.
• Repositório → a "loja" oficial de pacotes do Arch.
• AUR → loja da comunidade (programas extras).
• Rolling release → atualiza continuamente, sem "versões".
• root → o superusuário, dono de tudo.
• sudo → executar um comando como root.
• Terminal / shell → a tela preta onde você digita comandos.
• Kernel → o núcleo do sistema (veja a aba 🧠 O que é Kernel).

💡 Resumo: Arch é difícil só no começo. Depois de aprender pacman, yay e systemctl, você já consegue usar quase tudo.

🧠 O que é um Kernel?

Explicação simples, sem termos difíceis, para quem nunca mexeu com Linux.

💡 A ideia em uma frase

Kernel quer dizer "núcleo". É o cérebro do computador: a peça de software que fica no meio do caminho entre os programas e o hardware (as partes físicas, como processador, memória e disco).

🍽️ A analogia do restaurante (fácil de entender)

Imagine um restaurante:

• Você = o programa/app (faz o pedido)
• Cozinha, fogão e geladeira = o hardware (as peças físicas)
• O chefe de cozinha = o KERNEL

Você não entra na cozinha e mexe no fogão sozinho. Você faz o pedido ao chefe, e ele organiza tudo: quem usa o fogão primeiro, quanto de ingrediente usar, quando limpar.

O kernel é esse chefe: ele recebe os pedidos dos programas e decide quem usa cada peça do computador, quando e por quanto tempo.

⚙️ O que o kernel faz o dia inteiro

• Processos → decide qual programa roda agora (você tem vários apps abertos e poucos núcleos de processador)
• Memória → divide a RAM entre os programas
• Arquivos → controla a leitura e a gravação no disco
• Drivers → conversa com mouse, teclado, tela, Wi-Fi e câmera
• Rede → envia e recebe dados da internet
• Segurança → impede que um programa mexa na memória de outro

Tudo que você faz passa pelo kernel. Ele é o "meio de campo" do computador.

❓ Por que o Linux é um kernel?

Em 1991, um estudante finlandês chamado Linus Torvalds criou um núcleo de sistema e deu o nome de Linux (de Linus + Unix).

Esse nome, "Linux", é o nome do KERNEL — só o núcleo, não o sistema inteiro. O kernel sozinho não faz quase nada: não tem tela, não tem menu, não tem programa.

Por isso existem as distribuições: elas pegam o kernel Linux e colocam um monte de programas em volta para virar um sistema que dá para usar no dia a dia.

🧩 Kernel ≠ Sistema ≠ Distribuição

Essa confusão é normal. Veja a diferença:

• Kernel Linux → o núcleo (o cérebro). É basicamente um arquivo.
• Sistema operacional (GNU/Linux) → o kernel + os programas básicos.
• Distribuição → o sistema + instalador + loja + visual. Ex: Ubuntu, Debian, Arch, Kali.

Pense assim: o kernel é o motor. A distribuição é o carro completo (motor + rodas + bancos + pintura).

📱 Curiosidade: seu celular já usa Linux!

O Android roda em cima do kernel Linux. Sim! Enquanto você usa o celular, o kernel Linux está trabalhando embaixo de tudo. É por isso que dá para rodar Linux no Android — ele já está lá.

🛡️ Modo usuário × modo kernel

• Modo usuário → onde seus programas rodam, com "coleira curta": eles não podem mexer no hardware diretamente.
• Modo kernel → só o kernel entra aqui, e tem poder total.

Quando um programa quer algo do hardware, ele pede ao kernel (isso se chama "chamada de sistema"). É assim que o computador não vira uma bagunça.

✅ Resumo em 5 pontos

1. Kernel = núcleo, o gerente entre os programas e o hardware.
2. Linux é o nome do kernel, criado por Linus Torvalds em 1991.
3. O kernel sozinho não é um sistema — as distribuições completam.
4. Ubuntu, Debian, Arch e Kali usam o mesmo kernel Linux; só mudam os programas em volta.
5. Android também usa Linux — por isso ele roda no seu celular.
